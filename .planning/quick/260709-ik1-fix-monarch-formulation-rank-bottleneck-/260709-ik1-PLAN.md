  blockdiag_butterfly_multiply(x, w1, w2)
  Shape constraints: w1 shape (k, q, p), w2 shape (l, s, r); k*p == n (input),
  l*r == k*q. With k == l == nblocks, the constraint l*r == k*q forces r == q.

Current MonarchLinear.__init__ (torch_structured/monarch/monarch_linear.py):
  b = nblocks
  in_blksz  = ceil(in_features / b);  out_blksz = ceil(out_features / b)
  self.w1 = nn.Parameter(torch.empty(b, b, in_blksz))       # q = b  -> BUG
  self.w2 = nn.Parameter(torch.empty(b, out_blksz, b))      # r = b  -> BUG
